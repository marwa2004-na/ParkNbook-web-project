# ParkNbook-web-project
About the Project

ParkNbook is a web-based parking management system developed as an academic project. It aims to simplify parking management and reservations through a website connected to a database.

## Technologies Used

Frontend: HTML, CSS, JavaScript

Backend: PHP

Server Environment: WAMP Server

Database Management: phpMyAdmin (MySQL)

## Features

Web-based parking management

Parking reservation functionality

Database integration for managing system information

## Installation and Setup

Install and start WAMP Server.

Clone or download this repository.

Place the project folder inside the WAMP www directory.

Open phpMyAdmin in your browser, usually at http://localhost/phpmyadmin.

Create a database and import the project's provided .sql file, if included.

Update the database connection settings in the PHP configuration file.

Open the project in your browser at http://localhost/ParkNbook-web-project/.

The repository contains the website source code, database files, and related project resources.
